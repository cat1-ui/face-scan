# 阈值定档记录

> 记录日期：2026-10-12
> 系统：人脸识别系统（YuNet + SFace + opencv-python，纯 CPU）
> 采集设备：笔记本摄像头，硬件上限 1280×720

---

## 一、定档结论

| 项 | 值 |
|---|---|
| **定档阈值** | **0.50** |
| 出厂默认值 | 0.363 |
| 定档依据 | 五连测可分性数据（正/负样本分布） |

**判定逻辑**：相似度 ≥ 0.50 → 判为本人；< 0.50 → 拒识（"未识别"）。

---

## 二、可分性数据

| 指标 | 数值 |
|---|---|
| 正样本（同人）n=12 | 最小 0.903 / 中位 0.940 / 最大 0.960 |
| 负样本（不同人）n=9 | 最小 0.284 / 中位 0.321 / 最大 0.354 |
| **可分性间隔** | **0.549**（硬性门槛 ≥0.25，达标） |

## 三、定档阈值下的指标（实测）

| 指标 | 实测 | 目标（可接受） |
|---|---|---|
| 识别率（本人正确识别） | 100.0% | ≥ 90% |
| 误识率（认错人） | 0.0% | ≤ 3% |
| 拒识率（本人被拒） | 0.0% | ≤ 5% |

---

## 四、为什么定 0.50 而不是谷底 0.629

- 谷底（两峰中点）实测为 **0.629**，但本次正/负样本量偏小（正 12、负 9），且"不同人"仅两人样本，代表性有限。
- 直接采用 0.629 存在**小样本过拟合**风险：真实场景人员更多、光照姿态更复杂，负样本相似度可能上浮，0.629 下可能出现误识。
- **0.50 是稳健折中**：
  - 明显高于"不同人"上限 0.354 → 不误识；
  - 明显低于"同人"下限 0.903 → 不拒识；
  - 为真实环境的噪声预留了充足余量。

---

## 五、数据局限与后续建议

1. **样本量偏小**：建议后续补充更多人员（≥5 人）和更多光照/姿态样本后，重新校验阈值。
2. **"不同人"仅两人**：0.354 的负样本上限是两人数据，人群扩大后应重测。
3. **姿态/光照/距离维度**：本次因采集条件限制，同人鲁棒性数据（转头/距离/光照）未完整采集，建议后续补测。
4. 阈值已写入 `core/config.py` 的 `SIMILARITY_THRESHOLD`，如需调整用 `tools/set_threshold.py`。

## 六、采集过程记录（重要教训）

- 初版五连测因"两人同框、换人时前一人未离开画面"，导致 A/B 实际采到同一人（相似度 0.84，异常）。
- 排查方式：用 lena（确定不同的人）做对照实验，证明特征提取链路正常（lena vs 真人相似度 0.006）。
- 修正：改为"严格一次一人、分阶段存档"，最终得到正确数据（同人 0.93+ / 不同人 0.32）。
- **经验**：人脸采集"一次一人"是铁律，多人同框会导致检测结果张冠李戴。
